L’Étoile Gourmande.

Création d’un site web pour une boulangerie, permettant de présenter ses produits, de consulter le catalogue et de passer des commandes en ligne.

Rôle

Développement web

Stage en développement web · 2024/2025

HTML / CSS Supabase Stripe Vercel

Ma contribution.

Lors de mon stage, j’ai travaillé sur la création du site web de L’Étoile Gourmande, une boulangerie souhaitant présenter ses produits et proposer un système de commande en ligne.

J’ai utilisé HTML, CSS et JavaScript pour développer les différentes pages du site, créer les interfaces et mettre en place un catalogue permettant aux visiteurs de consulter les produits disponibles.

J’ai également utilisé Supabase pour mettre en place une base de données permettant de stocker et de gérer les informations liées aux produits et aux commandes.

Pour le paiement en ligne, j’ai intégré Stripe en mode test afin de simuler les transactions et de vérifier le fonctionnement du parcours de commande.

Enfin, j’ai déployé le site sur Vercel pour le rendre accessible en ligne et effectué plusieurs tests pour vérifier son fonctionnement sur ordinateur et sur mobile.
